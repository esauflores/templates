# Templates

Backend and backend-adjacent starter templates.

- [`lang/node-bun-cli/`](lang/node-bun-cli/) — TypeScript CLI package for Node.js, with Bun as its package manager.
- [`lang/node-bun-base/`](lang/node-bun-base/) — Hono API starter running on Node.js, with Bun as its package manager.
- [`lang/python-uv-base/`](lang/python-uv-base/) — FastAPI and Pydantic application managed with uv.
- [`ml/node-bun-inference/`](ml/node-bun-inference/) — Node.js/Hono CPU ONNX inference with Bun package management.
- [`ml/python-uv-inference/`](ml/python-uv-inference/) — FastAPI CPU ONNX inference managed with uv.
- [`stack/backend-base/`](stack/backend-base/) — PostgreSQL, Valkey, and SeaweedFS with Docker Compose.
- [`worker-base/`](worker-base/) — minimal Bun + TypeScript PostgreSQL worker using pg-boss.

Copy the template closest to your project and adapt it; each directory has its own README with setup instructions.
